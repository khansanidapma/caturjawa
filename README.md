# Catur Jawa
Web mini-game catur bergaya Jawa/Nusantara.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Untuk GitHub Pages, upload semua file/folder ke repository lalu aktifkan Pages dari branch utama.

Fitur:
- Papan catur interaktif
- Validasi gerakan dasar bidak
- Riwayat langkah
- Suara klik
- Dark mode
- Modal cara bermain
- Responsive
- Nuansa desain kayu dan Jawa


## Tutorial
Halaman utama sekarang memiliki tutorial lengkap: cara memilih bidak, memilih tujuan, pergantian giliran, cara menang, serta panduan gerakan setiap bidak dan tips strategi dasar.

## Update gameplay
Tombol Mulai Permainan aktif dan langsung membawa pemain ke papan. Undo sekarang benar-benar mengembalikan satu langkah.
